# Remoção de Background de Imagens

Aplicação desenvolvida em Python e Gradio para remoção
automática do fundo de imagens utilizando o modelo
BRIA RMBG-1.4.

## Demonstração

[Em breve: link para o Hugging Face Space]

## Sobre o projeto

Este projeto utiliza técnicas de visão computacional para
identificar o primeiro plano de uma imagem e remover
automaticamente seu background.

## Tecnologias

- Python
- Gradio
- Hugging Face Transformers
- BRIA RMBG-1.4
- Pillow
